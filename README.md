# Talkative

Real-time bilingual conversation translator for live two-person conversations. Built with Expo (React Native), Groq Whisper for speech-to-text, and Groq/DeepSeek LLMs for context-aware translation and AI suggestions.

---

## Current Features (as of v1.0 — April 2026)

### Conversation Flow

- **Auto-start mic** — microphone activates automatically when the conversation screen opens, no button tap required
- **Continuous hands-free listening** — mic stays live throughout the conversation, restarts immediately after each utterance is processed so no speech is missed
- **Automatic speaker detection** — identifies who spoke using Whisper's language detection matched against the two briefing languages; falls back to TTS timing (if the app just finished speaking aloud, the response is attributed to the other person)
- **No voice enrollment** — conversation starts instantly with no setup step

### Voice Activity Detection (VAD)

- Audio metering runs at 100ms intervals via expo-av
- **Adaptive noise floor calibration** — on the very first recording, samples ambient noise for 1.5s and sets the speech threshold at 75th-percentile noise + 12 dB margin (clamped between -50 dB and -20 dB)
- **Threshold persists across restarts** — calibrated threshold is reused for all subsequent recording windows, eliminating the 1.9s dead zone that previously caused consecutive utterances to merge
- **Silence threshold: 900ms** — utterance ends after 900ms of audio below threshold
- **Speaking indicator** — three purple dots appear in the conversation list while voice is detected; replaced by a spinner while transcribing/translating

### Speech-to-Text

- **Provider: Groq Whisper** (whisper-large-v3-turbo) — free tier, ~1-2s latency
- Accepts .m4a audio recorded at 44.1kHz, 128kbps AAC
- Returns transcript text + detected language code (used for speaker identification)

### Translation

Two modes selectable in the briefing screen:

- **Free** — MyMemory API, no API key needed, word-for-word
- **AI** — Groq Llama 3.3 70B or DeepSeek V4, context-aware, uses conversation history + goal

AI translation uses the last conversation history and the user's stated goal to produce natural, intent-preserving translations rather than literal ones.

### AI Suggestions

- After the other person speaks, 3 suggested replies appear as tappable chips
- Generated by Groq Llama 3.3 70B (or DeepSeek V4 if key provided)
- Ordered: assertive/direct first, softer alternative second, clarifying question third
- **Parallel execution** — suggestion generation fires simultaneously with TTS playback so chips appear almost immediately after the translated bubble
- Echo loop prevention: if the mic picks up the user reading a suggestion aloud (>=50% word overlap), that transcription is discarded

### Text-to-Speech

- expo-speech with per-language BCP-47 locale mapping
- Speaks translated text aloud after each utterance
- Mute/unmute via speaker button in header
- TTS end time tracked to assist speaker attribution on next utterance

### Briefing

**Brief mode** — user types a one-line goal used as context for AI translation and suggestions throughout the conversation.

**Detailed mode** — an AI coach interviews the user with targeted questions to build a full strategy profile. After 4-6 exchanges the coach signals readiness. The full interview transcript becomes the conversation context.

### API Keys

- **Groq API key** — STT (Whisper) + LLM fallback — free at console.groq.com
- **DeepSeek API key** — upgraded LLM for translation + suggestions — paid at platform.deepseek.com

Keys are entered in the briefing screen and stored in app state (not persisted between sessions).

## Tech Stack

- Framework: Expo SDK 54 / React Native 0.81
- Language: TypeScript
- Navigation: React Navigation v7 (native stack)
- Audio recording: expo-av
- Text-to-speech: expo-speech
- STT: Groq Whisper API (REST)
- Translation: MyMemory API (free) / Groq LLM / DeepSeek
- AI suggestions: Groq Llama 3.3 70B / DeepSeek V4

## Project Structure

```
src/
  screens/
    BriefingScreen.tsx          — setup screen (languages, keys, goal, mode)
    DetailedBriefingScreen.tsx  — AI coach interview before conversation
    ConversationScreen.tsx      — main conversation UI
  hooks/
    useAudioRecorder.ts         — VAD, recording lifecycle, isVoiceActive state
  services/
    stt.ts                      — Groq Whisper transcription
    tts.ts                      — expo-speech wrapper
    translator.ts               — MyMemory free translation
    reasoning.ts                — Groq/DeepSeek LLM calls (translation + suggestions)
    speaker.ts                  — speaker detection logic (language + TTS timing)
  context/
    AppContext.tsx               — global state (briefing, messages, API keys)
  constants/
    languages.ts                — supported language list with BCP-47 codes
```

## Running the App

**On device via USB (recommended):**
```bash
$env:JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"
npx expo run:android
```

**Dev server (same WiFi, Windows firewall rule for port 8081 required):**
```bash
npx expo start --clear
```

**Cloud build (standalone APK, no dev server):**
```bash
npx eas-cli build --profile preview --platform android
```

## Known Limitations

- Groq Whisper is file-based (not streaming) — true word-by-word real-time transcription is not possible with the current STT provider
- Both speakers must speak different languages for automatic speaker detection to work reliably; same-language conversations fall back to TTS timing heuristic
- API keys are not persisted — must be re-entered on each app launch
- Groq free tier has rate limits; heavy use may trigger them
